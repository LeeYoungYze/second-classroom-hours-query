==================================================
第二课堂学时自动查询工具 - 使用说明
==================================================

【文件夹里都有什么？】
- main.py             ：主程序代码（千万别删）
- account.json        ：账号密码配置文件（运行前在这里填账号）
- requirements.txt    ：依赖清单（告诉电脑需要提前安装哪些库）
- VC_redist.x64.exe   ：微软运行库安装包（非常重要，必装！）
- 使用说明.txt        ：就是你正在看的这个文件

--------------------------------------------------
【第一步：安装必备环境】
1. 先双击运行文件夹里的 `VC_redist.x64.exe`，一路点“下一步”安装到底。如果不装这个，程序百分之百闪退报错！（装完最好重启一下电脑）。
2. 电脑上必须安装了 Python。如果没有，请去官网（https://www.python.org/）下载安装包。安装时，第一页最下面一定要勾选 "Add Python.exe to PATH"（将 Python 添加到环境变量）。

--------------------------------------------------
【第二步：安装所需的库】
方法A（推荐）：如果你用的是 PyCharm 或 VS Code，直接用软件打开这个文件夹，打开 main.py，编辑器一般会提示你安装缺少的库，点一下“Install”即可。

方法B（命令行操作）：如果你习惯用命令行，请按 Win + R 键，输入 cmd 回车。然后通过 cd 命令进入这个文件夹的路径，然后输入以下命令并回车：
pip install -r requirements.txt
等待一堆进度条跑完，就说明库装好了。

--------------------------------------------------
【第三步：配置账号密码（超级重要）】
用记事本（或 VS Code）打开文件夹里的 `account.json` 文件。

情况一：你想【扫码登录】
保持原样，两个引号里什么都不要填（默认就是空的）。
"YOUR_ID" : "",
"YOUR_PWD" : ""

情况二：你想【全自动登录】
把你的学号和密码填进引号里面。（注意：必须用英文的引号，千万别用中文引号！）
"YOUR_ID" : "你的学号",
"YOUR_PWD" : "你的真实密码"
填好后，保存文件关闭即可。

--------------------------------------------------
【第四步：怎么运行？】
1. 运行前，一定要先关闭任何正在打开的 Excel 文件。
2. 用 PyCharm / VS Code 等编辑器打开 main.py 运行。
3. 如果你想用命令行运行，在刚才的 cmd 窗口里输入：python main.py 然后回车。

--------------------------------------------------
【第五步：程序是怎么工作的？】
程序会自动弹出一个浏览器窗口。
- 如果 `account.json` 里填了学号密码，它会全自动帮你算验证码、自动登录、自动抓数据、自动生成表格。
- 如果 `account.json` 是空的，它会停在二维码界面。请在弹出的浏览器里用手机扫码登录。登录成功后，回到黑框按一下【回车键】，程序就会继续去抓数据。
- 抓取成功后，文件夹里会“啪”地多出一个叫“第二课堂学时统计.xlsx”的彩色表格，双击打开就能看。

--------------------------------------------------
【想把表格存到别的地方？】
打开 main.py，拉到最下面，找到 SAVE_PATH = "" 这一行：
- 保持 "" 不变：表格就生成在 main.py 旁边（默认）。
- 填一个文件夹，例如 SAVE_PATH = r"D:\我的文件"：表格就存到那个文件夹里。
- 填完整文件路径，例如 SAVE_PATH = r"D:\我的文件\学时.xlsx"：连文件名也能一起改。
（路径前面的 r 不要删掉；文件夹不存在时程序会自动创建。）

--------------------------------------------------
【常见问题（QA）】
Q：黑框报错 "ModuleNotFoundError: No module named 'xxx'"？
A：说明你第二步没装库，或者装库的 Python 环境不对。请重新执行第二步。

Q：黑框一闪而过，或者报错找不到 python.exe？
A：你肯定没装第一步里的 VC_redist.x64.exe，快装一下。

Q：报错 JSONDecodeError 或者读取账号失败？
A：你改 `account.json` 的时候，格式改坏了。检查一下是不是把英文的双引号 " 改成中文的了，或者少写了逗号。把文件内容恢复成默认的样子再重新填。

Q：报错 Permission denied: '第二课堂学时统计.xlsx'？
A：你之前生成的表格正开着呢，没关掉。把 Excel 关了重新跑。

Q：扫码登录后，黑框没反应？
A：扫码成功后，必须要在黑框里按一下【回车键】，程序才知道你扫完了。
